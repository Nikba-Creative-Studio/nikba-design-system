Get started · npm

Install. Import. Build.

Use the stable npm package in your application. The examples below assume an ES module bundler such as Vite.

1. Install with npm

Terminal
npm install @nikba/design-system

2. Import CSS and configure your theme

JavaScript
import '@nikba/design-system/css';
import { setTheme, setGlassLevel } from '@nikba/design-system';

setTheme('frost'); // frost, mist or graphite
setGlassLevel('soft'); // off, soft or clear

3. Add your first component

HTML
<main class="nds-scope">
  <button class="nds-button nds-button--secondary" type="button">
    Preview project
  </button>
</main>

4. Initialize interactive components

JavaScript
import { initDialogs } from '@nikba/design-system';

// Run after the component markup is in the document.
const cleanup = initDialogs(document);

// Call cleanup() before removing the component.

Static components need CSS only. Interactive components such as Dialog, Select and Tabs also need their initializer; copy the matching HTML and JavaScript from the component reference.

Onest fonts are application-owned: load or self-host Onest separately. Read the foundations guide.

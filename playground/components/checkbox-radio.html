Checkbox and Radio

Checkbox supports independent selections. Radio chooses exactly one option from a visible, mutually exclusive group.

Install from npm, import @nikba/design-system/css, and place this markup inside .nds-scope. JavaScript examples use the public package exports.

JavaScript · Example 3
const parent = document.querySelector('#select-all');
const children = [...document.querySelectorAll('[name="permission"]')];
const selectedCount = children.filter((input) => input.checked).length;

parent.checked = selectedCount === children.length;
parent.indeterminate = selectedCount > 0 && selectedCount < children.length;

Usage guidance

Make the selection model obvious.

Use Checkbox for independent choices and Radio when one visible option must replace another.

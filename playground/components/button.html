Developer reference

Implementation

Install @nikba/design-system, import @nikba/design-system/css, and place this markup inside .nds-scope. JavaScript examples use the public package exports.

HTML · Example 1
<button class="nds-button" type="button">Save changes</button>
HTML · Example 2
<button class="nds-button nds-button--secondary" type="button">
  <span class="nds-button__icon" aria-hidden="true">
    <!-- Consistent line icon -->
  </span>
  Add member
</button>

  class="nds-button nds-button--secondary nds-button--icon nds-button--medium"

Content guidance

Start with a clear verb.

Write “Save changes,” “Add member,” or “Delete project.” Keep labels concise, specific, and on one line.

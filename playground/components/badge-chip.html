Badge and Chip

Badge communicates compact status or metadata. Chip is an interactive control that lets a user select a filter or option.

Developer reference

Implementation

Install @nikba/design-system, import @nikba/design-system/css, and place this markup inside .nds-scope. JavaScript examples use the public package exports.

HTML · Example 1
<span class="nds-badge nds-badge--success">
  <span class="nds-badge__dot" aria-hidden="true"></span>
  Approved
</span>
HTML · Example 2
<button class="nds-chip" type="button" aria-pressed="false">
  <span class="nds-chip__check" aria-hidden="true">
    <svg viewBox="0 0 16 16"><path d="m3.5 8 3 3 6-6" /></svg>
  </span>

  <span class="nds-chip__count">8</span>
</button>
HTML · Example 3
<div role="group" aria-label="Filter projects">

</div>

Usage guidance

Keep information and interaction distinct.

A Badge describes something. A Chip changes a selection. Do not style a Badge like an interactive control or use a Chip for static status.

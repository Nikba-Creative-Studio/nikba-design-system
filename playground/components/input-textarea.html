Adornments

Clarify format without replacing the label

Icons are decorative when the label already explains the value. Prefixes and suffixes stay outside the editable value.

States

Preserve meaning and entered values

Invalid feedback stays connected to the control. Disabled and readonly use their native HTML behavior.

Use at least four characters.

Textarea

Long-form text with vertical resize

Textarea grows vertically at the user’s request and never breaks the page width.

Include the context needed for someone new to understand the project.

View code · nds-field
HTML · Variant 1
<div class="nds-field"><label class="nds-field__label" for="project-brief">Project brief</label><textarea class="nds-textarea" id="project-brief" name="brief" placeholder="Describe the goal, audience, and desired outcome."></textarea><p class="nds-field__helper">Include the context needed for someone new to understand the project.</p></div>

Character count

Show limits before they become errors

The count updates while typing and changes emphasis near the native maximum length.

Used in project cards and search results.

0 / 160

Developer reference

Implementation

Install @nikba/design-system, import @nikba/design-system/css, and place this markup inside .nds-scope. JavaScript examples use the public package exports.

HTML · Example 1
<div class="nds-field">
  <label class="nds-field__label" for="email">Work email</label>
  <input
    class="nds-input"
    id="email"
    name="email"
    type="email"
    autocomplete="email"
    inputmode="email"
  />
</div>
HTML · Example 2
<div class="nds-input-shell">
  <span class="nds-input-shell__icon" aria-hidden="true">
    <!-- Search SVG -->
  </span>
  <input class="nds-input" id="project-search" type="search" />
</div>

</div>

Usage guidance

Ask only for information the experience needs.

Choose the correct native type, enable relevant autocomplete, and keep placeholder examples short.

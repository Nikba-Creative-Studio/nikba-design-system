Behavior model

Match control to consequence

Switches apply immediately, grouped edits wait for Save, session actions name their target, and destructive actions require confirmation.

PreferenceImmediate Switch
ProfileExplicit Save
AccountConfirmation Dialog

Responsive behavior

Keep every category reachable

The category list scrolls horizontally on compact screens while sections and actions stack in source order.

Developer reference

Implementation

Install from npm, import @nikba/design-system/css, and place this markup inside .nds-scope. JavaScript examples use the public package exports.

Usage guidance

Group settings by user intent.

Use plain category names, explain consequences beside controls, and reserve the final section for rare account-level actions.

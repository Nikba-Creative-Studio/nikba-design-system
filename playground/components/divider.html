Semantics

Expose structure only when it carries meaning

Use a native Horizontal Rule for a thematic break. Hide purely visual boundaries from assistive technology.

Semantic

Use <hr class="nds-divider" /> when the content changes topic.

Decorative

Use a neutral element with aria-hidden="true" for visual grouping only.

Usage guidance

Try spacing before adding a line.

Use Divider when space alone cannot communicate the relationship. Avoid repeated rules that fragment a simple page.

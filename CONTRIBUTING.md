# Contribuții

Nikba Design System este în etapa Alpha. Discuțiile și propunerile pot fi deschise prin GitHub Issues.

## Reguli de bază

- Folosește prefixul `nds-` pentru clasele publice.
- Definește culorile și dimensiunile reutilizabile prin tokenuri.
- Include stările hover, active, focus și disabled.
- Păstrează suportul pentru `prefers-reduced-motion`.
- Nu introduce efecte Liquid Glass bazate pe SVG displacement, canvas sau WebGL.

Înainte de un pull request:

```bash
npm run build
```
